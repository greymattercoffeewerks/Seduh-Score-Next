4 October 2026

The first live run.

Grey Matter Cup Taster Competition 2026 — Sports Hub, Bandar Seri Begawan. Not a rehearsal and not a demo: a real competition, scored from the first heat to the champion on this platform.

17 competitors→ 8 to the semis→ 4 to the final→ 1 champion

How it ran
Three rounds — five prelim heats, two semi-final heats and a final — eight heats in all, every one confirmed.
The deciding moment
The final ended in a three-way tie on correct cups, separated by time — exactly the kind of result the platform's tie handling exists to get right.
On the record
323 entries in the append-only change log by the end of the night, and the result published to the public archive at /results/ — podium first, at the organiser's choice.
What it taught us
It wasn't flawless, which is why it's worth writing down: a tablet timekeeper missed the beat on Stop, a misspelt name couldn't be fixed from the roster, the printed report ran off the page, and the event never marked itself concluded. All four are fixed — see the build log below.

The draw, under the floor
v4.0.0

Felt like building the hat before anyone gets to pull a name out of it.

Shipped

The engine for drawing a BTC round: a random first round, and a second round drawn either at random without repeats or from the first round's results, strongest against weakest. Throwdown
v3.6.0Live now

Felt like two names, one winner, and a bracket that can show its working.

Shipped

The third competition format: a one-on-one knockout. Competitors are seeded or drawn at random, and the draw stores its shuffle seed so it can be explained afterwards. Each match is decided by the judges' votes; the organiser confirms the winner, and confirming asks which winner they expect, so a stale screen can't confirm the wrong one. Byes and walkovers are handled, and the third-place match is still played when a semi-final ended in a walkover, as long as both losers are still in. It comes with an organiser console, its own projector and phone screens, a printable results page and a full eight-competitor test event. Scoring advancement lives in the format itself, because the shared ranking code takes one ranked list and a cut-off, which a knockout isn't; the only shared piece added was the seeded shuffle. Built with reviews that found two real offline-sync problems (a queued decision now closes voting) and nine test gaps, all fixed. Throwdown has not yet been run at a live event.

The operator's console
v3.4.0Live now

Felt like making the person who can add an organisation provable, not just trusted.

Shipped

Setting up a new organisation used to be hand-written database commands. There is now a separate console for the person who runs the platform: it creates an organisation, attaches its owner (a new login or an existing one), adds members and changes roles. It is deliberately narrow. It shows organisation names, members and dates, never an event, a score or a competitor, and there is no "sign in as" button. Every change is written to an append-only audit log, and the database itself, not the page, checks that the person is an administrator and has proved a second factor in the last hour. An organiser signed in on the same browser gets nothing from it. Built over 15 and 16 October with an adversarial test pass against the database functions behind it, and rolled out on 17 October as v3.4.0. Every action it offers has since been run against the real project.

Hardened for the room
v3.0.x

Felt like assuming the wifi will lie, and building so that it can't cost anyone a score.

Shipped

A run of pre-event reliability work for a venue where the wifi is somebody else's problem. Writes that fail on a bad connection stay queued and retry every fifteen seconds instead of being dropped, and every request now gives up after thirty seconds rather than hanging. Failures are sorted into "try again" (timeouts, rate limits, gateway errors) and "this will never work" (a genuine stale-score conflict), so one bad write can't block everything behind it — including a stale publish for a rehearsal event that has since been deleted.
