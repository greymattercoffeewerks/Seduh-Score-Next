Token layers and density (Petrol Kaizen P6)

Three layers: the ramp (--clr-teal-700, --radius-md), the semantic layer (--color-accent, --radius-sm, flipped by data-surface) and the role layer (roles.css), which names what a part uses and holds no value of its own. The table below is read from the page's computed styles, so it is what the browser resolves, in each surface.

data-density="compact" on a screen's root tightens padding, gaps and table cells (here a round of three matches and a table). A control keeps its 44px target: the row is shorter only by the padding around it. Opt-in per screen, no global switch. Normal on the left of each pair.
